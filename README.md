# TMDB_Clone
A movie discovery web app built with Vite and the TMDB API.
# 🎬 TMDB Clone A modern and responsive **TMDB (The Movie Database) Clone**
built using **HTML, CSS, and JavaScript**. This project fetches movie data from
the TMDB API and displays popular movies with a beautiful user interface. --- ##
🚀 Features - 🎥 Popular Movies - 🖼️ Dynamic Background Image - 📌 Movie Posters
- ⭐ Movie Rating - 📅 Release Date - 📖 Movie Overview - 📱 Fully Responsive
Design - ⚡ Fast and Lightweight --- ## 🛠️ Technologies Used - HTML5 - CSS3 -
JavaScript (ES6) - TMDB API --- ## 📂 Project Structure ``` TMDB/ │ ├──
index.html ├── style.css ├── script.js ├── assets/ └── README.md ``` --- ## 🔑
API This project uses **The Movie Database (TMDB) API**. Create your API key
from: https://www.themoviedb.org/ --- ## 📸 > Add your project
Example: ``` images/screenshot.png ``` --- ## 💻 Installation
Clone the repository ```bash git clone
https://github.com/MuskanSoni-Code/TMDB.git ``` Open the project folder ```bash
cd TMDB ``` Run using Live Server or open `index.html` in your browser. --- ##
