# 🎬 TMDB Clone

A fully responsive and modern **TMDB (The Movie Database) Clone** built using **HTML, CSS, and JavaScript**. This project uses the **TMDB API** to display movies, TV shows, trending content, detailed movie information, cast, reviews, watch providers, recommendations, and much more with a clean and interactive user interface.

---

## 📖 Overview

This project is a feature-rich clone of **The Movie Database (TMDB)** website. It allows users to discover movies and TV shows, view detailed information, explore trending content, and browse recommendations using real-time data from the TMDB API.

The application is designed with a modern UI, responsive layout, smooth animations, and an intuitive user experience.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/MuskanSoni-Code/TMDB.git
```

### Go to the Project Folder

```bash
cd TMDB
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

Open the local development URL shown in the terminal.
